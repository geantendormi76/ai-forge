## 3. ✅ 核心底层基石与最新战果（已验证的物理事实）

1. **VLM 原生多模态视觉通道 100% 贯通（里程碑突破）**：
   - 之前大模型之所以调用 OCR，是因为用户输入纯文本路径，大模型处于“盲人”状态，只能靠外部 OCR“摸象”。
   - 现已打通视神经通道：前端选图后自动封装为 `@"物理路径"` 格式，Pi 引擎自动解析图像 Base64 并塞入 OpenAI 视觉数据包，喂给 8000 端口挂载了 `--mmproj` 的 `llama-server`。
   - **实机打靶真值**：针对无文字的室内亲密互动测试图（`1.png`），大模型 100% 自主用眼睛看清，准确描述木地板、窗帘背景、女性闭眼神态与红色头饰、男性面部马赛克模糊处理，末尾主动指出“主要聚焦于人物互动，无文字信息”，未产生任何无意义的 OCR 调用，且消融权重零拒答！
2. **纯血 GGUF 模型热拔插系统 (`src-tauri/src/agent/model_hub.rs`)**：
   - 动态嗅探 `models/` 根目录下所有主脑 `.gguf` 与 `mmproj-*.gguf` 视觉眼球。
   - **双阶贪心防呆算法**：
     - 阶梯 1：提取 `8b`、`7b` 等参数量标记，主脑与眼球参数不一致直接一票否决；
     - 阶梯 2：剥离量化噪音后缀，基于 Jaccard 骨干 Token 贪心重合度打分，确保 8B 绝不挂错 7B 眼球，纯文本模型绝不胡乱挂载视觉眼球。
   - `LlmServer::restart_with_model`：互斥锁管理单例进程，换模型时先 kill 旧进程并休眠 600ms 等待显存归还驱动，再安全拉起新模型，重置 bridge 实例。
3. **前端冷白纸面温润交互闭环**：
   - 落地 `src/components/modals/ModelHubModal.vue`，展示模型卡片、体积、视觉能力徽标（`👁️ 原生视觉 VLM`）、在役状态，并提供“打开模型目录”按钮（用户扔入新 GGUF 点击刷新即见）。
   - `ChatComposer.vue` 接入 `@tauri-apps/plugin-dialog` 原生文件选择器与附件预览胶囊。
   - `MessageItem.vue` 彻底消除静态写死字符串，动态响应当前在役主脑名称。

## 6. 🚨 绝对不可逾越的“血泪踩坑铁律”（HARD CONSTRAINTS）

新接手的 AI 必须把以下警告作为最高优先级指令执行：

| 编号 | 致命病灶与踩坑史 | 绝对不可违反的铁律 |
| :---: | :--- | :--- |
| **01** | **破坏工具单一职责** | **严禁在通用原子工具（如 OCR/Table）中硬编码特定业务提示词**。工具只负责输出客观数据，业务交给大模型原生视觉或上层 Skill 插件！ |
| **02** | **PowerShell 文件落盘变量转义** | 凡涉及文件写入或源码覆盖，**必须强制使用** `Set-Content -Path "..." -Encoding UTF8 -Value @' ... '@` 原样单引号包裹，防止 `$` 符号引发语法错误。 |
| **03** | **命令行开头带 `#` 注释** | **严禁在提供给用户的 PowerShell 命令块中，以 `#` 开头写注释**，这会导致整块代码被 PS 误识别或跳过执行。 |
| **04** | **PowerShell Here-String 语法冲突** | 在向程序传递包含 `@` 的参数时，**严禁写成裸 `@"路径"`**（会被误认为 Here-String 开头引发 ParserError），必须用双引号整体包裹 `"@路径"`。 |
| **05** | **模型眼球错配引发张量崩溃** | 绝不能只靠简单包含匹配绑定 mmproj！**必须严格执行双阶贪心防呆（参数量绝对一致 + 骨干 Token 相似度门限）**。 |
| **06** | **大模型几何空间幻觉** | 严禁让 8B 大模型去处理 2D 坐标的重叠与对齐！所有表格文字缝合、排版切割，**必须在 Rust 后端用纯数学几何算法（IoA/AABB）完成**。 |
| **07** | **一次性倾倒大量修改** | **严格遵循 TDD 与一步一验证**。每次只给出一个明确的操作或全量代码，等待用户终端反馈后再进行下一步。 |
| **08** | **盲猜底座源码 (Rule 11)** | 若需要修改未在上下文中全量包含的文件，**严禁盲猜打补丁**。必须先输出 `Get-Content <文件路径>` 命令，白盒审计真实源码后方可给出修改方案。 |
